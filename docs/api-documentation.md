# API Documentation

Base URL: `http://localhost:8000`. Interactive Swagger docs are
auto-generated by FastAPI at `/docs` once the backend is running.

All endpoints except `/api/auth/*` and `/api/health` require
`Authorization: Bearer <JWT>`. Admin endpoints (`/api/admin/*`)
additionally require `role: ADMIN`.

## Auth
| Method | Path | Description |
|---|---|---|
| POST | `/api/auth/register` | Create a CUSTOMER account (+ savings account) and receive a JWT |
| POST | `/api/auth/login` | Authenticate and receive a JWT |

## Customer
| Method | Path | Description |
|---|---|---|
| GET | `/api/customers/me` | Current user profile |
| GET | `/api/accounts` | List your accounts |
| GET | `/api/accounts/{id}` | Account detail |
| POST | `/api/beneficiaries` | Add a beneficiary |
| GET | `/api/beneficiaries` | List beneficiaries |
| DELETE | `/api/beneficiaries/{id}` | Remove a beneficiary |
| POST | `/api/transactions/deposit` | Deposit funds |
| POST | `/api/transactions/withdraw` | Withdraw funds |
| POST | `/api/transactions/transfer` | Transfer to a beneficiary |
| GET | `/api/transactions` | List your transactions |
| GET | `/api/transactions/{id}` | Transaction detail |
| GET | `/api/risk/profile` | Your current risk profile |
| GET | `/api/notifications` | List notifications |
| PATCH | `/api/notifications/{id}/read` | Mark a notification read |

## Admin
| Method | Path | Description |
|---|---|---|
| GET | `/api/admin/dashboard` | Cards + chart data |
| GET | `/api/admin/customers` | List all customers |
| GET | `/api/admin/transactions` | List all transactions |
| GET | `/api/admin/fraud-cases` | List all fraud cases |
| GET | `/api/admin/fraud-reports` | List fraud incident reports |
| GET | `/api/admin/fraud-reports/{case_id}` | Full incident report detail |
| POST | `/api/admin/fraud-cases/{id}/approve` | Approve a held transaction |
| POST | `/api/admin/fraud-cases/{id}/block` | Block a held transaction |
| GET | `/api/admin/audit-logs` | List audit log entries |

## WebSocket
`ws://localhost:8000/ws/alerts?token=<JWT>` — pushes
`{"event": "notification", "notification": {...}}` events in real time
for both TRANSACTION and FRAUD notifications.
